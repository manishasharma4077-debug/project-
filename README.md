## Description of Work

The work focuses on performing Exploratory Data Analysis (EDA) and statistical modeling to understand construction project performance using Python. A simulated dataset containing 200 construction projects was created, including information about project types, locations, planned and actual durations, costs, workforce, equipment usage, material expenses, labour costs, delays, quality scores, and safety incidents.

The first stage involved data exploration and preprocessing, including examining data types, checking missing values, identifying duplicate records, and calculating descriptive statistics. Missing numerical values were handled using median imputation. Various visualizations were developed using Matplotlib and Seaborn, including scatter plots, histograms, boxplots, and a correlation heatmap, to identify patterns, relationships, and potential outliers.

Two statistical models were selected for analysis. Linear Regression was used to estimate actual construction costs based on selected project variables, while Logistic Regression was designed to classify projects as delayed or on time. The models were evaluated using appropriate performance metrics, including R², MAE, RMSE, accuracy, precision, recall, and F1-score.

Finally, the findings were used to develop recommendations for improving budget planning, resource allocation, and project scheduling. The analysis demonstrates how data-driven techniques can support informed decision-making and help construction managers monitor project performance more effectively.
